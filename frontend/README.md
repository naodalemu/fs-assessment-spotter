# Frontend

React 19 + Vite + MUI + react-leaflet. See the [project README](../README.md) for
setup, architecture and tests.

```bash
npm install
npm run dev      # http://localhost:5173, proxies /api to http://localhost:8000
npm run build    # set VITE_API_BASE_URL when the API is hosted elsewhere
npx vitest run
```
